# ProNet - Professional Networking Platform for Students

## About
ProNet is a LinkedIn-like professional networking platform designed specifically for higher education students. Built as part of the Cloud Counselage SIP UI/UX Project.

## Features
- 🔐 Authentication (Login & Multi-step Signup)
- 📰 Professional Feed with Posts & Interactions
- 💼 Job & Internship Search with Filters
- 👤 Detailed Profile Pages
- 🤝 Network Management
- 💬 Real-time Messaging Interface
- 🔔 Notifications Center

## Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- React Router DOM
- Lucide React
